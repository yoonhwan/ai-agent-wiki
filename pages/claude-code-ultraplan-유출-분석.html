Claude Code ULTRAPLAN 유출 분석

요약

Claude Code 소스코드에서 피처 플래그 44개 중 ULTRAPLAN이 발견됨. Matt Maher의 Plan Mode 벤치마크와 직접 연결되는 기능.

벤치마크 결과 (Matt Maher Planning Benchmark)

| 모델/도구 | 점수 |

|-----------|------|

| GPT-5.4 extra high (Codex CLI) | 95% |

| Opus 4.6 (Cursor) | 93% |

| Opus 4.6 (Claude Code execution) | 92.9% |

| Sonnet 4.6 (Claude Code) | 92.4% |

| Opus 4.6 (Claude Code plan mode) | 77% |

| Gemini 3.1 Pro (Gemini CLI) | 52% |

핵심 인사이트

1. **Plan 모드 끄세요** — Execution 모드에서 '계획을 세워줘'가 Opus 77%→92.9% (15점↑)

2. **도구가 모델보다 중요** — 같은 모델이 Cursor에 들어가면 전부 점수 상승 (예외 없음, 최대 16점)

3. Cursor가 이긴 이유: 계획 완료 후 자체 검증 → 원본 요구사항과 대조 → 빠진 항목 자동 추가

ULTRAPLAN이란?

  • 복잡한 계획 작업을 위한 별도 워크플로우
  • 현재 Plan 모드는 로컬 세션에서 돌아가지만, ULTRAPLAN은 별도 컨텍스트에서 실행
  • 계획 검증이 내장 — Maher가 Cursor에서 높은 점수를 본 이유와 같은 맥락
