TL;DR

  • **langchain-agent-skills**: LangGraph 프로덕션 패턴을 모듈화된 재사용 가능한 "스킬"로 패키징한 오픈소스 프로젝트
  • AI 코딩 어시스턴트(Claude Code, Cursor, Codex 등)가 **LangChain 도메인 전문가**처럼 동작하도록 만듦
  • **Progressive Disclosure** 패턴으로 컨텍스트 윈도우 효율적 관리

---

핵심 문제: 문서만으로는 부족하다

LangChain/LangGraph 문서는 훌륭하지만 **맥락적이지 않다**.

| 기존 문서 워크플로우 | 스킬 워크플로우 |

|---|---|

| 문서에서 맞는 페이지 검색 | 어시스턴트가 태스크 컨텍스트 감지 |

| 예제 읽고 관련 부분 찾기 | 적절한 스킬 자동 로드 |

| 코드 스니펫을 내 상황에 맞게 수정 | 프로덕션 레디 패턴 즉시 제공 |

| 설정 문제 수동 디버깅 | 스크립트/체크/구현 가이드 포함 |

반복되는 마찰 포인트

  • langgraph.json 설정 스키마
  • State reducer 패턴 선택
  • Retry 정책 설정
  • 배포 모드 결정 (Cloud/Hybrid/Standalone)
  • LangSmith 관측성 및 평가 설계

Agent Skills 기술 아키텍처

Progressive Disclosure 패턴 (3단계)

1. **Level 1 - 메타데이터** (항상 로드): 스킬 이름 + 설명 (~100단어). 시맨틱 매칭 트리거용. 최소 토큰 비용

2. **Level 2 - SKILL.md** (트리거 시 로드): 워크플로우 가이드, 의사결정 트리, 퀵스타트 패턴. 500줄 이하

3. **Level 3 - 번들 리소스** (온디맨드 로드): 상세 레퍼런스, 실행 가능 스크립트, 템플릿, 예제

**핵심**: 50+ 스킬도 성능 저하 없이 확장 가능 — 대부분 메타데이터 수준에서 대기

스킬 구성 요소

1. **SKILL.md** — YAML frontmatter + 핵심 워크플로우 가이드

2. **Scripts** — 프로젝트 스캐폴딩, 설정 검증, 자동화 스크립트

3. **References** — 온디맨드 상세 문서

---

7가지 프로덕션 스킬

A. langgraph-project-setup

  • 프로젝트 초기화 (langgraph.json, .env, 구조 생성)
  • Python / JavaScript/TypeScript 지원

B. langgraph-agent-patterns

  • 멀티에이전트 패턴: **Supervisor, Router, Orchestrator-Worker, Handoffs**
  • 패턴별 사용/회피 가이드 포함

| 패턴 | 사용 시점 | 피할 때 |

|---|---|---|

| Supervisor | 중앙 코디네이터 필요 | 에이전트 병렬 실행 필요 |

| Router | 정확히 1개 에이전트로 라우팅 | 여러 에이전트 기여 필요 |

| Orchestrator-Worker | 병렬 실행 필요 | 순차 의존성 존재 |

| Handoffs | 동적 에이전트 전환 | 흐름이 결정적 |

C. langgraph-state-management

  • State 스키마, 리듀서, 체크포인터 (InMemory/SQLite/PostgreSQL/CosmosDB)
  • operator.add vs 커스텀 리듀서 vs MessagesValue 패턴

D. langgraph-error-handling

  • 에러 분류: Transient → RetryPolicy / Recoverable → LLM 복구 루프 / User-fixable → interrupt()/resume()
  • 지수 백오프, Human-in-the-loop 에스컬레이션

E. langgraph-testing-evaluation

  • 단위 테스트 (개별 노드), 트라젝토리 평가 (전체 워크플로우)
  • LangSmith 데이터셋 통합, A/B 테스팅

F. langsmith-trace-analyzer

  • 트레이스 다운로드 + 필터링 → 자동 분류 (passed/failed/error) → 패턴 분석

G. langsmith-deployment

  • 배포 모드 선택 가이드 + langgraph.json 검증 + CI/CD 자동화 + 모니터링

| 모델 | 사용 시점 | 인프라 |

|---|---|---|

| Cloud | 관리형 인프라 원할 때 | LangSmith 호스팅 |

| Hybrid | 컴퓨팅 제어 필요 | 자체 인프라 + LangSmith API |

| Standalone | 완전 제어 필요 | 셀프 호스팅 |
