🏆 무료 아이콘 라이브러리 비교

1. Lucide Icons ⭐

  • **사이트**: lucide.dev
  • **아이콘 수**: 840+
  • **라이선스**: ISC (완전 무료, 상업용 OK)
  • **포맷**: SVG
  • **프레임워크**: React, Vue 2/3, Angular, Svelte, Solid, React Native, Preact, Eleventy
  • **특징**: 경량, 일관된 디자인, Feather Icons 후속작
  • **추천**: 웹앱에서 가볍고 깔끔한 아이콘이 필요할 때

2. Hugeicons

  • **사이트**: hugeicons.com
  • **아이콘 수**: 4,000+ (무료) / Pro 버전 별도
  • **라이선스**: 무료 티어 있음 (Pro는 유료)
  • **포맷**: Figma, React, SVG, CDN, NPM, WordPress, JSX
  • **특징**: 가장 많은 무료 아이콘 수, 다양한 스타일
  • **추천**: 아이콘 종류가 많이 필요할 때

3. Solar Icons 🆓

  • **사이트**: iconbuddy.com/solar / Figma Community
  • **아이콘 수**: 7,000+
  • **라이선스**: 완전 무료 (댓글에서 "Hugeicons과 달리 진짜 무료"라고 강조)
  • **특징**: 깔끔한 디자인, 모바일 친화적
  • **추천**: 무료에 민감한 프로젝트

4. Iconify 🌐

  • **사이트**: iconify.design
  • **아이콘 수**: 200,000+ (여러 라이브러리 통합)
  • **라이선스**: 라이브러리마다 다름
  • **포맷**: SVG, Web Component, React, Vue, Svelte 등
  • **특징**: 여러 아이콘 라이브러리를 **하나의 API로 통합** (Lucide, Material, FontAwesome 등 포함)
  • **추천**: 여러 스타일을 섞어 쓰거나, 통합 검색이 필요할 때

5. Heroicons

  • **사이트**: heroicons.com
  • **아이콘 수**: 300+
  • **라이선스**: MIT (완전 무료)
  • **제작**: Tailwind CSS 팀
  • **특징**: Tailwind 생태계와 찰떡, outline/solid/mini 3가지 스타일
  • **추천**: Tailwind CSS 프로젝트

6. Phosphor Icons

  • **사이트**: phosphoricons.com
  • **아이콘 수**: 1,200+
  • **라이선스**: MIT (완전 무료)
  • **포맷**: React, Vue, Flutter, Elm, SVG, Figma
  • **특징**: 6가지 웨이트 (thin, light, regular, bold, fill, duotone)
  • **추천**: 웨이트 변환이 자유로운 아이콘이 필요할 때

7. Tabler Icons

  • **사이트**: tabler.io/icons
  • **아이콘 수**: 5,200+
  • **라이선스**: MIT (완전 무료)
  • **특징**: 대규모 + 무료 + 일관된 디자인
  • **추천**: 아이콘 수와 무료 모두 중요할 때
