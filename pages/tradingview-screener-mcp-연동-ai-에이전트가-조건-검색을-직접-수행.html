TradingView Screener MCP 연동 — AI 에이전트가 조건 검색을 직접 수행

요약

TradingView Screener MCP 연동은 TradingView 스크리너 계열 기능을 AI 에이전트에서 자연어 조건 검색으로 호출해 결과를 표/DataFrame 형태로 다루는 흐름이다. 예시 사용 시나리오는 “RSI 30 이하, 시가총액 10억 달러 이상인 미국 주식”처럼 조건을 말하면 에이전트가 스크리닝 결과를 정리하는 방식이다.

핵심 포인트

  • 관련 프로젝트: deepentropy/tvscreener
  • 성격: TradingView 공식 API가 아닌 비공식 서드파티 Python 라이브러리
  • MCP Server Integration은 README 기준 v0.2.0에서 추가됨
  • 지원 자산군: Stock, Crypto, Forex, Bond, Futures, Coin
  • 결과 형식: Pandas DataFrame
  • 제공 도구 예시: discover_fields, custom_query, search_stocks, search_crypto, search_forex, get_top_movers

활용 가능성

  • 자연어 조건 → 스크리닝 쿼리 → 결과 표/요약 리포트 자동화
  • 미국 주식/암호화폐 조건 탐색 봇
  • 섹터·시총·오실레이터 기준 프리마켓 스캔 리포트
  • OpenClaw/MCP 기반 “조건 말하기 → 표 생성 → 브리핑” 흐름

주의사항

  • TradingView 공식 API가 아니므로 안정성, 약관, 장기 호환성 검토가 필요하다.
  • 스레드에 언급된 Pine Script 내부 사용 여부는 원본 작성자의 추정이며 추가 검증이 필요하다.
  • 실시간 자동 갱신/빈번한 호출은 레이트리밋과 정책 이슈 확인 후 사용해야 한다.
