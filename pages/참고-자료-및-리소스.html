설치 방법

1. 공식 SDK (Python)

pip install anthropic-agent-sdk

2. 공식 데모 클론

git clone https://github.com/anthropics/claude-agent-sdk-demos.git
cd claude-agent-sdk-demos/research-agent
uv sync
ANTHROPIC_API_KEY=your_key uv run python research_agent/agent.py

3. 커뮤니티 템플릿 설치

# 100+ 템플릿 한 번에
npx claude-code-templates

# 112개 에이전트 컬렉션
git clone https://github.com/wshobson/agents.git
cp -r agents/.claude/* .claude/

FAQ 리소스

Q: Agent Teams와 Subagent 중 뭘 먼저 배워야 하나요?

**A**: Subagent부터. Agent Teams는 Subagent의 확장.

  • Task 도구로 워커를 스폰하는 패턴 먼저 학습
  • 그다음 Teams로 확장

Q: 에이전트 팀 몇 명이 적당한가요?

**A**: **3-4명이 최적**

  • 출처: Addy Osmani의 가이드
  • 에이전트가 많으면 조율에 시간을 더 씀

Q: haiku로 코드 작성해도 괜찮나요?

**A**: 단순한 코드는 OK, 복잡한 로직은 sonnet

  • 리뷰어(읽기 전용): haiku 충분
  • 작가(콘텐츠): 반드시 sonnet
  • 백엔드/프론트 개발: haiku로 가능하나 판단 필요 시 sonnet

Q: 커뮤니티 템플릿 중 어디서 시작하면 좋나요?

**A**: claude-code-templates

  • 19.6K 스타로 검증됨
  • npx claude-code-templates로 즉시 설치
  • aitmpl.com에서 미리보기 가능

Q: Agent Teams가 아직 실험 기능인데 프로덕션에 써도 되나요?

**A**: 2026년 2월 기준 experimental

  • **개인/개발 환경**: 적극 활용 OK
  • **프로덕션**: 안정적인 SDK 방식(AgentDefinition) 권장
