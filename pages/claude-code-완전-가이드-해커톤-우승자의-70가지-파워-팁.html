---

📖 목차 (13개 파트)

Part 1: 에이전틱 개발자의 사고방식

  • **분해하고 정복하라** — 큰 문제를 작은 단위로 쪼개서 AI에게 명확한 지시
  • **계획 모드 vs YOLO 모드** — Shift+Tab ×2로 Plan Mode, --dangerously-skip-permissions로 YOLO
  • **컨텍스트 관리** — "AI 컨텍스트는 우유와 같다" (신선하게 유지!)

    • - 단일 목적 대화, HANDOFF.md로 선제적 압축, /context로 사용량 확인

  • **올바른 추상화 수준** — Vibe Coding(높은 추상화) ↔ Deep Dive(낮은 추상화) 상황별 선택
  • **미지의 영역에서 용감하게** — 모르는 기술도 AI와 반복적 탐구로 해결 가능

Part 2: 환경 설정과 필수 명령어

  • **커스텀 상태 라인** — 토큰 사용량, Git 브랜치, MCP 수 실시간 표시
  • **필수 슬래시 명령어** — /usage, /clear, /stats, /context, ! prefix (즉시 실행)
  • **CLAUDE.md** — AI를 위한 프로젝트 설명서. /init으로 자동 생성, 간결하게 유지
  • **터미널 별칭** — alias c='claude', alias cc='claude --continue'
  • **세션 관리** — --continue, --resume, /rename, /export

Part 3: 생산성 핵심 기술

  • **음성 코딩** — 타이핑 40WPM vs 말하기 150WPM (3.75배 속도 차이!)
  • **터미널 출력 추출** — pbcopy, VS Code, GitHub Desktop 활용
  • **키보드 단축키** — Esc Esc(되감기), Ctrl+R(역방향 검색), Ctrl+S(프롬프트 임시 저장)
  • **Vim 모드** — /vim으로 활성화
  • **입력 박스 단축키** — Ctrl+G로 외부 에디터에서 편집

Part 4: 컨텍스트 관리의 예술

  • **HANDOFF.md 기법** — 대화가 길어지면 핸드오프 문서 생성 → /clear → 새 세션에서 로드
  • **터미널 탭 멀티태스킹** — 각 탭은 독립적인 "두뇌"
  • **대화 복제** — /clone(전체), /half-clone(반복제, 컨텍스트 절반)
  • **realpath** — 절대 경로로 혼란 방지

Part 5: Git & GitHub 워크플로우

  • **자동 커밋 & Draft PR** — gh CLI 연동
  • **Git worktrees** — 병렬 브랜치 작업 (브랜치 전환 없이)
  • **대화형 PR 리뷰** — Claude가 보안 이슈, N+1 문제, 에러 핸들링 누락 발견
  • **cc-safe** — 위험한 승인 명령어 감사 도구 (npm install -g cc-safe)

Part 6: 고급 기능 - MCP, Hooks, Agents

  • **MCP** — Playwright(브라우저), Supabase(DB), Firecrawl(크롤링) 등 외부 연동

    • - ⚠️ 10개 미만 MCP, 80개 미만 도구 유지 권장

  • **Hooks** — PreToolUse/PostToolUse로 위험 명령어 차단, 알림 등 결정론적 제어
  • **Skills** — 재사용 가능한 지식 조각 (Claude가 자동 호출)
  • **Agents (서브에이전트)** — 독립 200k 컨텍스트, 병렬 실행, 전문화된 작업 위임
  • **Plugins** — Hooks + Skills + Agents + MCP를 번들로 배포

Part 7: 시스템 최적화와 자동화

  • **시스템 프롬프트 슬림화** — ykdojo가 19k → 10k 이하로 절반 감소 (58개 패치)
  • **지수 백오프** — 장시간 작업 상태 확인 간격을 점진적으로 늘리기
  • **백그라운드 실행** — Ctrl+B로 백그라운드, 서브에이전트 병렬 실행
  • **자동화의 자동화** — Level 0(복붙) → Level 7(Hooks 자동화)까지 발전
  • **Headless 모드** — claude -p "prompt"로 CI/CD 파이프라인 통합

Part 8: 컨테이너와 샌드박스

  • **Docker 컨테이너** — YOLO 모드는 반드시 컨테이너 안에서!
  • **워커 Claude 오케스트레이션** — 메인 Claude가 tmux로 컨테이너 내 워커 Claude 조율
  • **Sandbox 모드** — /sandbox로 신뢰할 수 있는 명령어만 자동 승인

Part 9: 브라우저 통합과 웹 자동화

  • **네이티브 Chrome 통합** — claude --chrome
  • **Playwright MCP** — 헤드리스 브라우저, E2E 테스트 자동화
  • **Gemini CLI** — Claude 접근 불가 웹사이트의 대체 수단

Part 10: 실전 활용 사례

  • 작성-테스트 사이클(TDD), 글쓰기 도우미, 연구 도구, DevOps 엔지니어
  • 범용 인터페이스 (비디오 편집, 오디오 전사, 디스크 정리 등)
  • 출력 검증: 테스트 → GitHub Desktop → Draft PR → 자기 검증

Part 11: 고급 패턴과 철학

  • **10억 토큰 규칙** — "사용이 최고의 학습"
  • **개인화된 소프트웨어 시대** — 자신만의 맞춤형 도구 제작
  • **지식 공유의 선순환** — 공유하면서 더 많이 배운다

Part 12: 고급 기능과 SDK

  • **Extended Thinking** — ultrathink 키워드로 최대 32k 토큰 내부 추론
  • **LSP 통합** — IDE 수준 코드 인텔리전스
  • **Claude Agent SDK** — 10줄로 에이전트 만들기
  • **팀 설정 공유** — .claude/team-settings.json

Part 13: 학습 로드맵

  • **초급 (1-3개월)**: 기본 명령어, CLAUDE.md, 컨텍스트 관리, Git 통합
  • **중급 (3-12개월)**: MCP, Hooks, Skills, 컨테이너, 서브에이전트
  • **고급 (1년+)**: 시스템 프롬프트 패치, 커스텀 MCP 서버, 멀티에이전트 오케스트레이션, SDK

💡 인상적인 인사이트

1. **"AI 컨텍스트는 우유와 같다"** — 신선하고 압축된 상태 유지가 핵심

2. **YOLO 모드 = "보호되지 않은 성관계"** — 반드시 컨테이너 안에서!

3. **자동화의 자동화** — 반복 3회 이상이면 자동화, 그 자동화도 자동화

4. **AI는 부조종사, 주인공은 당신** — 최종 결정과 책임은 개발자의 몫
