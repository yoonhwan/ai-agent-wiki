"2025년은 분명히 MCP의 해였는데, 많은 MCP들이 SKILLS로 대체되고 있는 트렌드!"

**@_petercha** (바이브코딩 Vibe coding) 님이 소개하는 스킬 매장지 + 스킬이 각광받는 이유.

---

1️⃣ Vercel Skills — skills.sh

**사이트**: https://skills.sh

  • Vercel이 만든 **에이전트 스킬 디렉토리**
  • 눈에 띄는 스킬들:

    • - **find-skills**: AI가 필요한 스킬을 스스로 찾고 설치하는 메타 스킬 🔥

    - **react-best-practices**: React 베스트 프랙티스

    - **design-guide**: 디자인 가이드

  • **지원 에이전트**: Antigravity, Claude Code 등 거의 모든 에이전트 지원
  • 설치: npx skills add <skill-name>

---

💡 왜 Skills가 MCP를 대체하는가?

| 관점 | MCP | Skills |

|------|-----|--------|

| 실행 방식 | 서버 프로세스 필요 | 마크다운 + 스크립트 (경량) |

| 로드 방식 | 항상 연결 | Progressive Disclosure (필요 시 로드) |

| 이식성 | 서버 종속 | 에이전트 간 포터블 |

| 설치 | 서버 설정 필요 | npx skills add 한 줄 |

→ 스킬은 **컨텍스트 오염 없이** 에이전트 성능을 극대화하는 경량 패턴
