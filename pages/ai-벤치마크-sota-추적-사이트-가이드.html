📖 SOTA란?

**SOTA** = **S**tate-**O**f-**T**he-**A**rt

정의

"현재 존재하는 기술/모델 중 **가장 좋은 성능**을 내는 것"

번역

  • **직역**: 최첨단 기술
  • **의역**: 업계 최고 성능
  • **AI 맥락**: 벤치마크 1등, 기존 모델들을 모두 능가

예시로 이해하기

**"Voxtral Small achieves SOTA on English short-form transcription"**

→ 영어 짧은 음성 전사에서 **현존하는 모든 모델 중 1등** 성능

**"Beats GPT-4o but not SOTA"**

→ GPT-4o는 이겼지만 **1등은 아님** (다른 더 좋은 모델 존재)

AI 논문/블로그에서의 용법

✅ SOTA 달성 = 자랑할 만한 일

"Our model achieves SOTA on FLEURS benchmark"
→ 우리 모델이 FLEURS 벤치마크에서 1등 먹었다! 🏆

⚠️ Near-SOTA = 아쉽게 2등

"Performance is competitive but not SOTA"
→ 경쟁력 있지만 1등은 아님

📊 SOTA vs. Baseline

  • **SOTA**: 현재 최고 성능
  • **Baseline**: 비교 기준 (보통 이전 1등 모델)

왜 SOTA가 중요한가?

**벤치마크 = 시험 성적표**

  • SOTA = 전교 1등
  • 논문/블로그에서 "우리가 1등!"이라고 어필하는 용도
  • ⚠️ 실제 프로덕션에서는 **비용, 지연시간, 안정성**도 중요 (1등 성능만으로 선택 안 함)

🏆 SOTA 벤치마크 사이트 (카테고리별)

1️⃣ Papers with Code ⭐ 최고 추천

**URL**: https://paperswithcode.com/sota

특징

  • 📊 **모든 AI 분야** 통합 벤치마크 순위
  • 🔄 논문 발표되면 실시간 업데이트
  • 📈 벤치마크별 리더보드 + 그래프
  • 🔓 오픈소스 모델 중심

주요 카테고리

  • **STT**: Speech Recognition, Speech Translation
  • **LLM**: Language Modelling, Question Answering
  • **Image Gen**: Image Generation, Text-to-Image
  • **Vision**: Image Classification, Object Detection
  • **Audio**: Audio Generation, Music Generation
  • **NLP**: NER, Sentiment Analysis, Translation
  • **Video**: Action Recognition, Video Generation

예시 링크

https://paperswithcode.com/task/speech-recognition

LLM (Language Modeling):
https://paperswithcode.com/task/language-modelling

Image Generation:
https://paperswithcode.com/task/image-generation

Object Detection:
https://paperswithcode.com/task/object-detection

**URL**: https://huggingface.co/spaces/open-llm-leaderboard/open_llm_leaderboard

  • 🔓 **오픈소스 LLM 전용** 리더보드

3️⃣ LMSYS Chatbot Arena 🥊

**URL**: https://chat.lmsys.org/?leaderboard

특징

  • 👥 **사람이 직접 평가** (블라인드 테스트)
  • 🆚 두 모델 대결 → 승자 투표 → ELO 점수
  • 🌍 실시간 업데이트 (GPT, Claude, Gemini 등 포함)
  • 🔒 상업 모델 + 오픈소스 모델 모두 포함

왜 중요한가?

  • 벤치마크 성적 ≠ 실제 사용 경험
  • Chatbot Arena는 **실전 체감 성능** 반영
  • "사람이 느끼기에 더 좋은 답변"을 찾음

평가 카테고리

  • **Overall** (전체)
  • **Coding** (코딩)
  • **Math** (수학)
  • **Creative Writing** (창작)
  • **Instruction Following** (지시 따르기)
  • **Hard Prompts** (어려운 질문)

현재 상위권 (2026-02-08 기준)

1. GPT-4 Turbo

2. Claude 3.5 Sonnet

3. Gemini 1.5 Pro

4. GPT-4o

5. Claude 3 Opus

7️⃣ ElevenLabs TTS Research 🔊

**URL**: https://elevenlabs.io/research

특징

  • 🎵 **TTS (Text-to-Speech)** 품질 비교
  • 🧑‍🔬 자연스러움, 발음 정확도, 감정 표현
  • 📊 MOS (Mean Opinion Score) 기반 평가
  • 🎭 다국어, 다감정 지원 비교

평가 지표

  • **Naturalness** (자연스러움): 1~5점
  • **Intelligibility** (명료성): 발음 정확도
  • **Emotion** (감정 표현): 의도한 감정 전달력
  • **Similarity** (유사도): 원본 화자와의 일치도

8️⃣ Stanford HELM 📊

**URL**: https://crfm.stanford.edu/helm/

특징

  • 🎓 **스탠포드 공식** 종합 벤치마크
  • 🔍 정확도 + 공정성 + 편향성 + 견고성
  • 📈 여러 시나리오 통합 평가
  • 🌍 다양한 도메인 (뉴스, 의료, 법률 등)

평가 항목 (7개 차원)

1. **Accuracy** (정확도): 문제 정답률

2. **Calibration** (신뢰도): 모델의 자신감과 실제 정확도 일치

3. **Robustness** (강건성): 입력 변화에 대한 안정성

4. **Fairness** (공정성): 인구 통계학적 그룹 간 성능 차이

5. **Bias** (편향성): 사회적 편견 측정

6. **Toxicity** (유해성): 유해 콘텐츠 생성 빈도

7. **Efficiency** (효율성): 추론 속도, 메모리 사용량

시나리오 예시

  • 뉴스 요약
  • 의료 질의응답
  • 법률 텍스트 분석
  • 감정 분석
  • 코드 생성

  • Artificial Analysis로 가성비 확인

3️⃣ 오픈소스 vs. 상업 모델

  • **오픈소스**: 커스터마이징 가능, 비용 절감, 데이터 보안
