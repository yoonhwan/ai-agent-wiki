Scrapling — 1인 개발자가 만든 적응형 웹 스크래핑 프레임워크

원본: https://www.threads.com/@jisang0914/post/DXmUnGNGo4z
작성자: @jisang0914 (Threads, 2일 전, 43.6K views)
GitHub: https://github.com/D4Vinci/Scrapling

한 줄 요약

이집트 개발자 Karim Shoair가 혼자 만든 파이썬 웹 스크래핑 프레임워크. **GitHub 38,700 스타**, BS4 대비 최대 **1,679배 빠름**, Cloudflare 봇 차단 **자동 우회**, 사이트 리디자인되어도 셀렉터를 **자동 재탐색**(adaptive=True 한 줄).

핵심 키포인트

  • **개발자 커뮤니티 첫 반응 4개** → 18개월 뒤 **GitHub 전체 트렌딩 1위**
  • **2026년 2월 v0.4 출시** → 주당 8,000 스타 폭증 → WIRED 보도
  • **Cloudflare CTO 코멘트**: "우리가 바꾸면 저쪽도 바꾼다" (창과 방패 구도)
  • **만든이 Karim Shoair**: 원래 침투 테스트(보안) 도구 개발자 → 봇 차단 시스템을 뚫는 법을 아는 사람이 만든 우회 도구
  • 설치: pip install scrapling 한 줄, 오픈소스

기존 도구와 다른 점 3가지

| # | 차별점 | 효과 |

|---|--------|------|

| 1 | BS4 대비 **1,679배 속도** | 대규모 크롤링 비용/시간 단축 |

| 2 | **Cloudflare 등 봇 차단 자동 우회** | 차단 회피용 별도 코드 불필요 |

| 3 | **셀렉터 자동 재탐색** (adaptive) | 사이트 리디자인되어도 코드 유지 |

3번이 핵심 — Adaptive Selector

  • 요소를 처음 저장할 때 **다차원 지문**을 DB에 저장

    • - 태그 / 텍스트 / 속성 / DOM 경로 / 부모 / 형제

  • 사이트 구조가 바뀌면 모든 요소를 순회하며 **유사도 점수** 계산
  • 코드 변경: adaptive=True 한 줄 추가로 끝
  • 기존 스크래핑은 CSS 셀렉터 하나 바뀌면 코드 다시 짜야 함

MCP 서버 (2026년 3월 말 업데이트)

  • Claude / Cursor 등 AI 도구에 웹 스크래핑 능력 **직접 부착**
  • 경쟁 MCP 서버: 페이지 **전체 HTML**을 AI에 넘김 → 토큰 폭발
  • Scrapling MCP: CSS 셀렉터로 **필요한 부분만 추출** → **토큰 비용 절감**
  • 시사점: AI 에이전트가 직접 웹을 긁는 시대의 인프라 후보

바이럴 그림자 — 밈코인 사건

  • 바이럴 직후 누군가 $Scrapling 밈코인을 만듦
  • Karim이 순간적으로 홍보 → 5시간 만에 가격 폭락
  • WIRED 인용: "사기꾼들" — 투자자 반응
  • Karim이 게시물 삭제 + 사과: "돈은 자선 단체에 기부, 어떤 이익도 취하지 않겠다"
  • 교훈: 오픈소스가 바이럴 되면 개발자에게도 의도치 않은 시험이 옴

WIRED 기사 인용

"OpenClaw 유저들이 Scrapling으로 Cloudflare를 대규모로 우회하고 있다."

당시 OpenClaw이 GitHub 역사상 **가장 빠르게 성장한 레포**였고, 그 유저들이 Scrapling을 조합해 쓴 게 바이럴의 직접적 원인.

⚠️ 여기서 언급된 "OpenClaw"은 원문 표기 그대로. 우리 OpenClaw 프로덕트와 동명인지 동일 도구인지 검증 필요.

큰 그림

  • 웹 스크래핑 = AI 학습 데이터의 입구
  • Cloudflare가 막고 → 스크래퍼가 뚫고 → Cloudflare가 다시 막는 군비 경쟁
  • 그 최전선에 38,700 스타짜리 **1인 오픈소스**가 있다

자비스 활용 후보 ⭐

  • **crawl-lab 프로젝트**와 직접 연결 — 현재 BS4/playwright 기반이면 마이그레이션 검토
  • **agent-browser 대안/보완** — adaptive selector로 셀렉터 깨짐 문제 해결
  • **OpenClaw MCP 통합** — Scrapling MCP 서버를 OpenClaw에 추가하면 Slack/대시보드에서 직접 스크래핑
  • **news-digest 스킬 안정성** — 뉴스 사이트 리디자인에도 셀렉터 자동 복구
  • **Cloudflare 우회 대체** — 기존 우회 도구(undetected-chromedriver 등) 대체 가능성
